# NOMA — versión premium

## Qué incluye
- Diseño responsive, minimalista y pensado primero para móvil.
- Generador de menú semanal (desayuno, comida y cena) con filtros básicos.
- Recetas con ingredientes e instrucciones.
- Lista de compra agrupada, con cantidades orientativas y casillas para marcar.
- Copiar lista, guardar preferencias y progreso en el dispositivo.
- Manifest y service worker para experiencia instalable/offline.

## Publicación en GitHub Pages
1. Sube **el contenido de esta carpeta** a la raíz del repositorio (incluye `icons/`).
2. En Settings → Pages elige `Deploy from a branch`, `main`, `/(root)` y Save.
3. Espera a que termine la publicación y abre la URL del repositorio.

## Importante antes de vender
Este es un prototipo funcional. Los precios son orientativos, el catálogo de recetas es pequeño y las cantidades de la lista son aproximaciones, no una planificación nutricional ni cálculo exacto de costes. No incluye cuentas, sincronización entre dispositivos ni pagos. Valida la demanda con usuarios reales antes de invertir más.
